# Demucs UI

Stem separator GUI. See the [root README](../README.md) for clone (submodules), build, and itch/GitHub shipping.

Apple Silicon uses the `workers/demucs-mac-silicon` submodule ([demucs-mac-silicon](https://github.com/nicapotato/demucs-mac-silicon)). Windows uses `workers/demucs-windows` ([demucs-windows](https://github.com/nicapotato/demucs-windows)).
