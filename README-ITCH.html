Application that can take mp3, wav, or PSARC (Rocksmith 2014 CDLC) and extract mp3 or wav stems (isolated tracks for drums, guitar, bass, vocals, piano, other) using Demucs (6-stem htdemucs_6s).

Download the build that matches your machine. Output is a RocknRoller-compatible folder so you can mute the chart guitar and play over the rest of the band.

macOS Apple Silicon — MLX C

demucs-mlx-c-arm-mac-silicon.zip

Native C worker on MLX + Metal. No PyTorch. This is the Apple Silicon download: it is faster than the ONNX build on the same Mac.

macOS Intel — ONNX

demucs-onnx-mac-x64.zip

Frozen ONNX Runtime worker, CPU. The Intel macOS wheel has no GPU provider.

Windows x64 — ONNX

demucs-onnx-windows.zip

ONNX Runtime with DirectML. Uses an NVIDIA, AMD, or Intel GPU when one is present, and falls back to CPU.

Linux x64 — ONNX

demucs-onnx-linux-x64.zip

ONNX Runtime, CPU. AMD and Intel GPUs stay on this build.

Optional builds

demucs-mlx-py-arm-mac-silicon.zip — Apple Silicon MLX Python worker.

demucs-cuda-windows.zip — Windows NVIDIA CUDA (native C). Needs a Turing or newer GPU and a recent driver.

demucs-torch-windows.zip — official Meta Demucs + PyTorch. Large download because it includes the CUDA runtime. AMD and Intel GPUs fall back to CPU.
